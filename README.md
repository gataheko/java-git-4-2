# java-git-4-2
The Invoice App is a simple command-line tool that helps calculate discounts for customers based on their customer type (Retail or Commercial) and their order subtotal. It supports multiple invoice calculations in a single session and formats all output as proper currency and percentages.


Accepts two customer types: Retail (r) and Commercial (c)

Applies tiered discount rates based on subtotal amount

Displays discount percentage, discount amount, and final total

Formats output using Java's built-in NumberFormat for currency and percentages

Loops continuously, allowing multiple invoices per session

Gracefully exits when the user chooses to stop
